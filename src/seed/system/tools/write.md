Write a doc whole by its handle — the frontmatter (kind, description, load) and the body, as
a file holds them; creates it or replaces it. Your own scope (agent/…) is yours to write.

- handle: the doc's handle as the index prints it: scope/name — system, shared or agent
  (your own), then the doc's name
- content: the whole text, frontmatter included
